# Lab 1 Grupp 1 FSM Game

## Run the game

### Requirements
Python 3.10–3.14 (SPADE does not support 3.15 yet).

### Create virtual environment
```bash
$ python3.13 -m venv .venv
$ source .venv/bin/activate
```

### Install packages
```bash
$ pip3 install -r requirements.txt
```

### Run the game
```bash
$ python3 main.py
```
